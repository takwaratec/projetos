### RESENHA TÉCNICA
Este manual técnico detalha uma metodologia para a criação, publicação e preservação de projetos científicos e técnicos utilizando uma infraestrutura colaborativa de conhecimento aberto, focada na combinação GitHub e Zenodo. O objetivo central é combater a perda de projetos digitais, comum no Brasil, fornecendo-lhes um endereço permanente e rastreável. A metodologia emprega o GitHub para versionamento de documentos, colaboração global e publicação automática de portais web via GitHub Pages, e o Zenodo para a geração de DOIs (Digital Object Identifiers) permanentes e a preservação digital por no mínimo 20 anos em servidores do CERN. O processo é facilitado pelo uso do VSCode como interface visual para o GitHub, eliminando a necessidade de comandos de terminal, e pelo MkDocs para transformar arquivos Markdown em um portal público acessível. O manual estrutura-se em três partes para diferentes perfis de usuário – desde iniciantes em GitHub até aqueles que buscam DOI ou automação – com "próximos passos concretos" para aplicação imediata. O ecossistema proposto articula um "Repo Mãe", um "Repo de Projetos" e um "Portal Público", sob uma licença CC BY 4.0, garantindo a replicabilidade, a citação e a disseminação de conhecimento de bioeconomia e outras áreas no contexto da Plataforma Amazônia Regenerativa.
